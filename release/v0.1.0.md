# Solis_DJImic_Hotkey v0.1.0 便携版

适用 Windows 11 x64。完整解压 `Solis_DJImic_Hotkey_v0.1.0_windows-x64.zip`，双击 `DJI 听写.exe`，点「启动绑定」。本机和 RDP 的默认听写快捷键均为 `Ctrl+Shift+D`。在 ChatGPT 输入框内短按 DJI 开始听写，再短按结束。

- 中文主窗口可分别改键、打开高级设置和测试 DJI 按钮。
- 主窗口和托盘均可控制开机自启。开机自启和音量加拦截初始关闭。
- 自带 AutoHotkey v2.0.31。升级时保留 `config/DJI_Mic_Hotkey.ini`，更多操作见包内「使用说明.html」或[项目手册](../docs/MANUAL.md#portable)。

同时提供 AutoHotkey 对应源码 ZIP 和 `SHA256SUMS.txt`。入口 EXE 来自官方运行时归档，字节保持一致。Windows 对该文件报告无 Authenticode 签名，可用 SHA256 校验下载的 ZIP。[M3 验收计划](../docs/milestones/M3_PLAN.md)
