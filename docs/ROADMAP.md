# 便携版路线图

目标版本为 `v0.1.0`。行为与验收由 [PRD](PRD.md) 定义。当前实施计划见 [M1](milestones/M1_PLAN.md)。

| 里程碑 | 阶段结果与退出条件 | 依赖 |
| --- | --- | --- |
| M0 基线 | 已验收 `343a008`。确立便携版需求、界面基准、阶段安排以及可核对的发布合同。 | 已确认的界面和产品范围 |
| M1 主界面与兼容 | 双击显示主窗口，支持独立录入本机与 RDP 快捷键以及启停。根目录旧脚本和维护工具兼容性通过。 | M0 |
| M2 设置、测试与打包 | 高级设置、托盘、登录启动和只观察的按钮测试就绪。包内运行时、离线启动、配置保留、发布目录和内含文件通过隔离验证，形成候选包。 | M1 |
| M3 真机验收 | 用候选包验证本机及 RDP 窗口和全屏听写、拔插、重连、音量行为与完整重新登录自启。验收通过后再执行公开发布。 | M2 候选包、真实设备、RDP 与用户重新登录 |
