# Solis_DJImic_Hotkey 项目蓝图

更新：2026-10-29。状态：常用界面汉化已应用；按钮已正式启用，本机/RDP 窗口/全屏及拔插/重连实测通过。

## 两个目标

1. **汉化 AutoHotkey。** 针对本机 `D:\AutoHotkey` 的实际界面、菜单和设置进行简体中文汉化，保持原功能。
2. **绑定 DJI 按钮。** 复用 AutoHotkey，让 DJI Mic Mini 2S 发射器按钮可以绑定本机与 RDP 的听写快捷键。

## 使用场景

用户在 Acer 本机和 HP Z6 G4 的 mstsc RDP 之间切换，通过发射器按钮启动对应位置的 ChatGPT 听写，将语音转成输入框文字。当前预期绑定为本机 `Alt+C`、远端 `Alt+X`。

## 实施原则

直接利用现有 AHK v2 与脚本，先做简单可用的改动。汉化与按钮绑定可以分别推进；调查和验证只服务于这两个目标，不单独建设诊断产品或管理平台。

## 范围

不重写 AutoHotkey，不开发语音识别服务，不默认新增专用 GUI、驱动、服务或数据库。实际需要额外改动时再明确理由与范围。

行为与验收见 [PRD.md](PRD.md)。按“先备份汉化，再处理按钮绑定”的顺序实施，不扩大到无关系统改动。

用户上手与维护说明集中于 [MANUAL.md](MANUAL.md)，覆盖从官方软件下载到日常使用、维护和恢复的完整路径；操作说明不代表已经修改系统设置。
