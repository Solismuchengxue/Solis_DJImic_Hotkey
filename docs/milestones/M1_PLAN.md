# M1 主窗口与兼容入口

在已验收的 M0 基线 `343a008` 上，按 [PRD](../PRD.md) 和[界面图](../ui/README.md)实现主窗口。

### Task 1: 主窗口与旧入口

在 `app/` 内实现便携主窗口，沿用根目录 AHK 绑定核心。打开时显示停止状态，绑定与托盘共用运行状态，重复打开时唤起原窗口。两端快捷键均默认 `Ctrl+Shift+D`。改键先验证再保存，失败时保留旧值。旧脚本仍可从原路径单独运行。

以现有 AHK 规则、便携状态测试和停止态窗口验证作为证据。负责人将固定提交交给测试者和独立审查者。登录自启、按钮观察及成品包移交 M2。
