# M2 设置、按钮测试与便携打包

在已验收的 M1 `b95719b` 上实现[便携版需求](../PRD.md)中剩余的设置和候选制品。

### Task 1: 设置与观察

使用同一份 INI 保存高级设置。主窗口和托盘从当前用户的同一启动快捷方式读回开机自启状态。按钮测试进入观察态，只处理匹配的按钮信号。结束或关闭时恢复原运行状态。

分别覆盖无效设置、自启正常和路径迁移、自有与同名其他入口、停止和暂停状态按钮测试及退出。验证使用临时目录和模拟事件。

### Task 2: 便携制品

从固定提交打包，核验运行时和对应源码后输出 ZIP、上游源码和校验值。以[发布约定](../../release/README.md)为准。核对干净目录、双击入口、配置路径、许可、升级和关闭行为。记录当前验证环境及仍需真实设备或干净系统的项目，交由独立审查者复验。
