# M0 便携版基线

基于原部署源码 `000f33b` 和已确认的 [Logo 与界面图](../ui/README.md)，为 `v0.1.0` 固定后续实现所需的范围和发布约定。

1. 归入现有 README、Logo 和设计图。更新[蓝图](../BLUEPRINT.md)和[需求](../PRD.md)，保留原部署事实与旧入口。
2. 固定[发布合同](../../release/README.md)与[机器可读清单](../../release/manifest.json)，锁定上游 AHK 版本和归档 SHA256，明确候选包的目录及 Git 跟踪范围。
3. 核对文档链接、清单字段、忽略规则、设计资产和 Git diff。由负责人组织独立审查，消化具体发现后进入 [M1](../ROADMAP.md)。

M0 退出条件是批准的设计与需求可定位，发布合同能够据此验证后续候选包，原脚本、配置与运行入口保留。包体验证与真机验收分别在 M2、M3 完成。
