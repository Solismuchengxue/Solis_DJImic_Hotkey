# M3 真机验收与正式发布

以候选包内 `resources/build.json` 的源码提交和 `SHA256SUMS.txt` 的 ZIP 哈希登记验收对象。更换候选 ZIP 后重做相关验收。

1. 在未安装 AutoHotkey 的 Windows 11 x64 普通用户环境中断网解压。用含中文和空格的目录启动，移动目录后再次启动，并验证旧配置迁移与自启失效提示。
2. 用 DJI 短按开始和结束听写。在本机、RDP 窗口和 RDP 全屏分别检查 ChatGPT 输入框出现文字。接收器重插后复验本机，RDP 重连后复验远端。
3. 核对音量拦截打开时音量不增加，停止、暂停及退出后键盘音量加恢复。按钮测试中短按应显示「已收到按钮信号」。点击「再测一次」可继续观察，期间不触发听写，结束后恢复原运行状态。
4. 通过便携版打开开机自启。完整注销并重新登录，检查同一便携副本进入托盘并能触发听写。随后撤销测试用自启。
5. 独立审查者按同一提交和 ZIP 哈希核对证据。通过后在 GitHub Release 上传便携 ZIP、AutoHotkey 对应源码 ZIP 和校验文件。重新下载并核对资产及哈希。

无法取得实际硬件、RDP、干净 Windows 或完整登录证据时，候选包保留在本地 `release/`。
