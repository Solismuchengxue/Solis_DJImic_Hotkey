DJI 听写便携版

当前实测设备为 DJI Mic Mini 2S。

  1. 完整解压 ZIP 到可写的目录，双击 DJI 听写.exe。将 USB-C 接收器插到本机，确认发射器已配对，麦克风选择 Wireless Mic Rx。
  2. 在 ChatGPT 的「设置 → 语音 → 听写 → 单击快捷键」设为 Ctrl+Shift+D，在聊天输入框用键盘验证开始、结束和转写。改键时需与软件中对应的一行匹配。
  3. 点「启动绑定」，确认显示「运行中」。点进聊天输入框，短按一次 DJI 发射器按钮开始听写，再按一次结束。用 RDP 时，先在远程桌面中启用麦克风重定向。

测试与维护

  • 「测试 DJI 按钮」只检查按钮信号。检测到信号后点「完成」，再回到 ChatGPT 输入框验证转写。
  • 运行时关闭窗口会收进托盘。托盘可暂停、恢复、切换开机自启和退出。
  • DJI 短按听写时若同时调高音量，在「高级设置」勾选「拦截音量加键」并保存。绑定运行时也会拦截实体键盘的音量加键。可用 Windows 音量滑块调音量，或取消勾选、暂停、停止绑定或退出程序来恢复音量加键。
  • 移动目录前先从托盘退出。移动后打开应用，点「登录时自动启动（路径已变，点击修复）」。升级时将旧包的 config/DJI_Mic_Hotkey.ini 复制到新版的对应位置。
  • 主界面的「开发者模式」打开原版 AutoHotkey 控制面板。编程帮助在官方网页。
