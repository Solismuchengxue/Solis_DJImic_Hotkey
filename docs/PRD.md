## 目标二：绑定本机和 RDP 听写快捷键

复用 AutoHotkey 及现有脚本，将 DJI Mic Mini 2S 发射器按钮映射为对应位置的听写快捷键；需要支持调整绑定，不预设必须另做 GUI。

| 场景 | 预期行为 |
| --- | --- |
| Acer 本机 | 按钮触发本机听写快捷键，当前预期为 `Alt+C` |
| HP Z6 G4 的 mstsc RDP 前台 | 按钮触发远端听写快捷键，当前预期为 `Alt+X`；窗口与全屏均适用 |

验收要求：

- 核对两端实际听写绑定，按钮触发正确目标，不误触另一端或无关窗口。
- 本机/RDP 切换、接收器拔插和 RDP 重连后能正常使用；停用后不残留本工具的绑定。
- 处理已报告的按钮额外增加音量问题，尽可能只处理 DJI，保留键盘音量键原行为；有设备限制时如实说明影响。
- 远端听写使用 RDP 重定向的 Acer 麦克风；目标是听写转文字，不是实时语音对话。
- 启动后应显示聊天输入框内的听写，并将文字放入该输入框；仅出现全局听写浮窗不算通过。验证时保持真实聊天输入框焦点，不弹测试 GUI 取代目标窗口。

## 已有事实

- 本机为 Acer，AHK v2.0.31 位于 `D:\AutoHotkey\v2`；原脚本使用全局 `$Volume_Up` 按 mstsc 前台分流，原文件已备份保留。
- 连接为“发射器 → 无线 → 手机用 USB Type-C 接收器 → Acer USB-C”，没有手机参与。用户确认 `Wireless Mic Rx` 是 DJI 接收器；只读元数据关联到 VID `2CA3` / PID `4011`。
- 实机 Raw Input 观察确认 DJI 来自 MI_00/Col01、Consumer usage E9，键盘来自另一设备；临时观察已退出，普通文本键与音频没有记录。
- 用户确认手动本机 Alt+C、远端 Alt+X 均能启动听写（Reported），截图确认它们是应用自带“单击快捷键”（一次开始、再次结束），按住/双击入口关闭。正式代码的基本场景、拔插和 RDP 重连均已由用户实测通过。

## 当前按钮实现

项目根 `DJI_Mic_Hotkey.ahk` 是维护源，已更新到 `D:\AutoHotkey` 并正式运行；运行配置以安装目录 INI 为准，项目根 INI 是默认关闭拦截的示例。使用 AHK 调用 Windows Raw Input，仅匹配已实测的 DJI VID/PID、接口与集合；E9 按下边沿触发一次，具有去抖、暂停、配置读取和设备变化缓存清理。按前台进程选择本机/远端快捷键，发送前再次检查焦点。规则回归见 `tests/hotkey_rules.ahk`。

`[Behavior] BlockVolumeUp=1` 是显式可选的全局音量加拦截；缺省值为 0。它结合系统注册热键与 AHK 键盘钩子，并在 RDP 前台/窗口几何变化后重装钩子，覆盖实测的全屏路径。**会同时拦截键盘音量加，不是只阻断 DJI 的设备独立方案。** 用户已授权正式启用，安装目录 INI 当前为 1；用户已自行添加登录自启（Reported），重新登录效果未单独确认。

暂停、退出或关闭该选项会取消注册、停用音量钩子并停止重装定时器；恢复时显式重新启用钩子。无效配置保持旧配置，注册冲突时不假装已拦截。没有事后恢复音量、驱动、服务、注册表或 RDP 设置改动。

用户确认本机、RDP 窗口、全屏均能听写且不再增加音量；正式启用后，保持同一实例完成接收器拔插与 RDP 断开重连，两项也均正常且不增加音量。日志补充确认两端的 DJI 触发与音量钩子回调；用户看到的输入框结果与日志发送分开记录。本机日志与排查历史保留在本地。

`tests/volume_guard_rules.ahk` 验证配置、暂停和失败恢复；`tests/volume_guard_lifecycle.ahk` 实测原生热键占用/释放及重复停止，不捕获设备或发送按键。原设备筛选、路由与去抖回归保持通过。
