## 目标一：汉化 AutoHotkey

直接汉化 `D:\AutoHotkey` 本体的界面、菜单、设置及常用提示。优先利用可靠现成资源；缺少合适语言包时，修改现有 UX 界面文件。

验收要求：

- 实际使用的主界面和设置可用简体中文操作，文字清楚、布局正常。
- 原来的菜单动作、启动配置和编辑器设置功能保持正常。
- 修改有原文件恢复办法；未覆盖的界面明确列出，不把中文帮助当成全部界面已汉化。

已修改并应用 7 个 UX 文件：Dash、启动设置、编辑器设置、新建脚本、安装/移除界面和 Window Spy。主菜单动作以固定条目分派，确认按钮保留稳定 ID，中文解释器选项仍读写原英文配置值。7 文件 AHK /Validate、隔离菜单/配置回归和常用界面实机查看通过；未实际执行安装/卸载。

汉化覆盖常用 UX，解释器内置错误正文和部分模板名称仍为英文。原部署机器的默认帮助采用 wyagd001 的社区译本 2.0.19，并保存了原英文 2.0.31。用户已确认中文目录和正文，安装文件与英文备份的 SHA256 均已核对。[帮助文件清单](../localization/help_manifest.json)

## 目标二：绑定本机和 RDP 听写快捷键

复用 AutoHotkey 及现有脚本，将 DJI Mic Mini 2S 发射器按钮映射为对应位置的听写快捷键。便携版提供界面调整绑定，原部署可继续通过 INI 调整。

| 场景 | 预期行为 |
| --- | --- |
| Acer 本机 | 按钮发送 `Ctrl+Shift+D`，由本机 ChatGPT 听写 |
| HP Z6 G4 的 mstsc RDP 前台 | 按钮发送 `Ctrl+Shift+D`，由远端 ChatGPT 听写，适用于窗口与全屏 |

验收要求：

- 核对两端实际听写绑定，按钮触发正确目标，不误触另一端或无关窗口。
- 本机/RDP 切换、接收器拔插和 RDP 重连后能正常使用；停用后不残留本工具的绑定。
- 处理已报告的按钮额外增加音量问题，尽可能只处理 DJI，保留键盘音量键原行为；有设备限制时如实说明影响。
- 远端听写使用 RDP 重定向的 Acer 麦克风；目标是听写转文字，不是实时语音对话。
- 启动后应显示聊天输入框内的听写，并将文字放入该输入框；仅出现全局听写浮窗不算通过。验证时保持真实聊天输入框焦点，不弹测试 GUI 取代目标窗口。

## 已有事实

- 本机为 Acer，AHK v2.0.31 位于 `D:\AutoHotkey\v2`；原脚本使用全局 `$Volume_Up` 按 mstsc 前台分流，原文件已备份保留。
- 连接为“发射器 → 无线 → 手机用 USB Type-C 接收器 → Acer USB-C”，没有手机参与。用户确认 `Wireless Mic Rx` 是 DJI 接收器；只读元数据关联到 VID `2CA3` / PID `4011`。
- 实机 Raw Input 观察确认 DJI 来自 MI_00/Col01、Consumer usage E9，键盘来自另一设备；临时观察已退出，普通文本键与音频没有记录。
- 用户曾用本机 `Alt+C`、远端 `Alt+X` 完成窗口/全屏、拔插及 RDP 重连测试（Reported）。2026-11-18 两端统一为 `Ctrl+Shift+D`，用户确认本机和 RDP 聊天输入框中的 DJI 短按听写均正常（Reported）。

## 当前按钮实现

项目根 `DJI_Mic_Hotkey.ahk` 是维护源。原部署实例运行的是先前复制到 `D:\AutoHotkey` 的已验证版本，使用安装目录的 INI。便携分支复用同一源码，维护和验收在候选包中进行。Windows Raw Input 仅匹配已实测的 DJI VID/PID、接口与集合。E9 按下边沿触发一次，支持去抖、暂停、配置读取和设备变化缓存清理。按前台进程选择本机或远端快捷键，发送前再次检查焦点。规则回归见 `tests/hotkey_rules.ahk`。

`[Behavior] BlockVolumeUp=1` 是显式可选的全局音量加拦截；缺省值为 0。它结合系统注册热键与 AHK 键盘钩子，并在 RDP 前台/窗口几何变化后重装钩子，覆盖实测的全屏路径。**会同时拦截键盘音量加，不是只阻断 DJI 的设备独立方案。** 用户已授权正式启用，安装目录 INI 当前为 1；用户已自行添加登录自启（Reported），重新登录效果未单独确认。

暂停、退出或关闭该选项会取消注册、停用音量钩子并停止重装定时器；恢复时显式重新启用钩子。无效配置保持旧配置，注册冲突时不假装已拦截。没有事后恢复音量、驱动、服务、注册表或 RDP 设置改动。

用户确认本机、RDP 窗口、全屏均能听写且不再增加音量；正式启用后，保持同一实例完成接收器拔插与 RDP 断开重连，两项也均正常且不增加音量。日志补充确认两端的 DJI 触发与音量钩子回调；用户看到的输入框结果与日志发送分开记录。本机日志与排查历史保留在本地。

`tests/volume_guard_rules.ahk` 验证配置、暂停和失败恢复；`tests/volume_guard_lifecycle.ahk` 实测原生热键占用/释放及重复停止，不捕获设备或发送按键。原设备筛选、路由与去抖回归保持通过。

## 便携版 v0.1.0

- 在 Windows 解压并双击程序，使用包内 AHK v2.0.31 离线打开主窗口，初始绑定为停止。若便携版已在运行，双击显示已有主窗口。新用户可启用绑定，分别录入并确认本机和 RDP 的组合键。新配置两端默认 `Ctrl+Shift+D`。
- 主窗口和托盘同步显示绑定、自启状态。托盘可打开主窗口、暂停或恢复绑定、切换登录自启和退出。自启由用户设置，按当前用户登录时以 `--tray` 隐藏主窗口启动绑定。
- 主窗口底部的 GitHub 图标与「使用说明」共用[项目手册入口](https://github.com/Solismuchengxue/Solis_DJImic_Hotkey/blob/main/docs/MANUAL.md)，版本号放在底部右侧。
- 高级设置提供全局音量加拦截 `BlockVolumeUp` 和去抖间隔 `DebounceMs`。新配置默认关闭拦截，去抖默认 `250 毫秒`，范围为 `0–2000 毫秒`。开启拦截前标明会影响所有设备的音量加键。
- 按钮测试只观察 DJI 发射器信号，结束后恢复此前绑定状态。实际听写按照本机和 RDP 的 ChatGPT 输入框结果验收。
- 采用一个便携 INI。停止绑定后可随便携目录搬移配置，升级流程须保留原 INI。
- 既有 AHK 脚本、INI 及启动入口须通过回归。便携包的源版本、运行时和目录见[发布约定](../release/README.md)。

界面见[确认的概念图](ui/README.md)。便携版公开发布前，须单独验证 Windows 新目录解压启动、真机本机/RDP 听写、接收器拔插、RDP 重连及完整注销后重新登录的自启。原部署的历史结果仍按原部署记录。[路线图](ROADMAP.md)
